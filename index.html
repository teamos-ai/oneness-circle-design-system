I.
Principles · Five Rules

Geometry & restraint.

Every choice in this system answers to these five. When in doubt, default to the softer corner, the lower elevation, the longer breath of space.
  1. 01

    Sharp geometry, never soft.

    Containers hold their corners. The square is our only shape — buttons, chips, sticky bars, hero badges, cards, inputs. A single 4px softening is permitted on the smallest decorative touchpoints. Round corners, pills, and capsule forms do not exist in this system.

  2. 02

    Bento, not banner.

    Information arranges as nested sharp-cornered panels of different sizes, never as a single wide stripe. Variety in width and tint creates editorial rhythm without breaking the grid — every join is a clean 90°.

  3. 03

    Whisper-quiet elevation.

    Shadows are diffuse and tinted with warm ink — they suggest depth, never announce it. No drop shadows above e-3 on hover. No glow, no neumorphism.

  4. 04

    Pastel surface, anchor ink.

    Card backgrounds use the 50/100 tints; type uses the 700/800 anchor. The contrast is calm, never harsh. Pure white and pure black are forbidden.

  5. 05

    Coral is a verb.

    It only appears on call-to-action, on the ASEA dot, and on a single data point per layout. If you can read it without scanning — too much.

II.

Colour.

Five anchor colours, each extended into a ten-stop scale. Pillar membership is encoded in surface tint; ink stays warm and constant. Ivory and Sacred Gold appear in every composition.

There are exactly five colours that matter, and they answer to roles, not moods. Ivory is the page she stands on. Sacred Gold is the thread she traces between pillars. Sage is the breath, Blue is the bloodstream, Violet is the throne. Coral, the only voice raised above a whisper, is reserved for the moments she acts.

Foundations · 02 · Two voices

Typography.

Two families. The tension between them is the brand — Cormorant carries soul, Jost carries precision. No third family is ever introduced, including for display.

Hierarchy is built from family, weight, and tracking. Display work uses Cormorant in light weights; instrumental work uses Jost in precise mid weights. Where ordinary brands shout with size or weight, this one whispers with the difference between a serif italic and a tracked uppercase grotesque.

Foundations · 03 · Breath

Spacing.

A four-pixel base with editorial leaps at 32, 48, and 96 pixels. Use the named tokens — never raw pixel values. Breath is the brand.

Two rhythms operate at once. The micro-rhythm — 4, 8, 12, 16, 20 — handles the inside of cards and the gap between siblings. The macro-rhythm — 32, 48, 64, 96 — handles the silence between sections. They never trade roles; never compromise.

Motion.

Soft easing, never bouncy. Durations correspond to the size of the change: a chip recolours in 120 ms; a panel reveals in 400.

VIII.
System · 01 · Naming & pillars

Taxonomy.

A predictable naming convention so any designer, developer, or partner reads the system the same way. Token names tell you what something is, not where it goes.
The formula
--toc· category· role· variant

Prefix is locked. Category names the foundation (color, type, s, r, e, dur). Role is the semantic intent. Variant is optional scale or state.

--toc-color-gold-500raw colour at scale stop
--toc-bg-canvassemantic role · surface intent
--toc-r-0radius · sharp default
--toc-s-8spacing · scale step (32 px)
--toc-e-2elevation · hover level
--toc-dur-3duration · 400 ms step
--toc-type-displaytype · role: display
--toc-fg-mutedforeground · muted state
08 · b
Component naming

Components follow BEM-lite. Block is the component (btn, card, chip). Modifiers follow with a hyphen.

.btn .btn-primary .btn-coral .btn-sm .card.tint-sage .chip.outline
Modifiers are added with hyphen-suffix or chained class. State (:hover, :active) is never encoded in the class name.

Iconography.

A sanctioned set of solid, sharp-geometric glyphs that speak the brand's languages — essential oil & ritual, science & chemistry, nature & farming, wellness, meditation, sound, feminine cycles, and the social surface where it all meets the audience. Every icon inherits currentColor so the same glyph reads in violet ink, ivory on dark, or gold thread depending on where it sits.

Click any tile to copy its <use> reference to your clipboard. Drop the SVG into any markup as <svg><use href="#icon-name"/></svg> and size with width / height or font-size. XVIII.
Patterns · 03 · Discipline

Do & Don't.

When tokens are honoured, this system is unfakeable. When they're broken, the brand collapses to ordinary.
Do · Honour the system
i.
Compose layouts from three to five bento panels of varying span.
ii.
Use a single pillar tint per layout (sage or blue or violet).
iii.
Hand off interactivity to square, sharp-cornered controls — buttons, chips, sticky bars.
iv.
Reserve coral for one CTA per layout (max 10% surface).
v.
Keep Sacred Gold present — even as a single thin line or one chip.
vi.
Hold the radius scale: r-0 default on every container; r-xs (4px) only on decorative micro-touchpoints.
Don't · Break the system
i.
Mix sage, blue, and violet in the same layout.
ii.
Use pure white (#fff) or pure black (#000).
iii.
Use rounded corners, pills, or capsule shapes on any container or control.
iv.
Introduce a third font, even for "display impact."
v.
Use coral as decoration, border, or background fill.
vi.
Stack drop shadows or exceed e-3 on hover.
"A finished system is a quiet system. Restraint is the strategy. The further you go, the less the system feels invented — and the more it feels inevitable."

// components/ui/reveal.tsx
"use client"
import { useEffect, useRef } from "react"
import { cn } from "@/lib/utils"

type Props = {
  children: React.ReactNode
  delay?: 0 | 1 | 2 | 3
  className?: string
}

export function Reveal({ children, delay = 0, className }: Props) {
  const ref = useRef<HTMLDivElement>(null)

  useEffect(() => {
    const el = ref.current
    if (!el) return
    if (matchMedia("(prefers-reduced-motion: reduce)").matches) {
      el.classList.add("is-visible")
      return
    }
    const io = new IntersectionObserver(
      ([entry]) => {
        if (entry.isIntersecting) {
          el.classList.add("is-visible")
          io.disconnect()
        }
      },
      { rootMargin: "0px 0px -8% 0px", threshold: 0.06 }
    )
    io.observe(el)
    return () => io.disconnect()
  }, [])

  return (
    <div
      ref={ref}
      data-reveal-delay={delay}
      className={cn("reveal", className)}
    >
      {children}
    </div>
  )
}

She did not choose between the ritual and the research. She chose both.

editorial image · 16:9

There is a register the world is not ready to recognise — the woman who keeps a botanical altar and a peer-reviewed shelf in the same room. She does not perform the contradiction. She lives it, and in living it she rewrites the small grammar of every morning.

"The morning anchor, the cellular hydrogel, the salon at dusk: a single grammar runs through them all."

The pillars were never separate. They were the same instinct, expressed at three different altitudes. Once she stopped apologising for keeping all three, the work simplified — and the audience arrived already fluent in the language.
